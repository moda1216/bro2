python3.11 -m mlx_lm.server --model mlx-community/Qwen2.5-7B-Instruct-4bit --port 11434 --ctx 4096 --temperature 0
provider 配置：{"type":"openai","baseUrl":"http://127.0.0.1:11434/v1","model":"mlx-community/Qwen2.5-7B-Instruct-4bit","apiKeyOptional":true,"includeUsage":true,"stream":true,"timeoutMs":120000,"maxRetries":2}
