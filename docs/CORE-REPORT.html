0 · 脉络：为什么会走到这一轮

v2.30.0
把「第三方已有公开成绩的任务集」直接给 bro2 跑（Terminal-Bench 公开 verifier 双向反证），kilo 端点得 50% positioning-only。同时留下一个隐患：测量脚本只声明了 maxSteps=12。
v2.31.0
用逐轨迹诊断证伪了上一版的「空转不肯停」结论：真实机理是 guard(kind=tokens) 静默熔断早于产出落地，以及模型约束求解不全。做了预注册 A/B（K=2）检验预算软预警，判据未全成立／无差异（如实记录，不宣称增益），机制默认关闭。
附带发现：16 次运行 steps 最高 9 就撞 token 熔断 —— v2.30.0 的读数是「预算配置失真」下的读数，不是公平读数。
v2.32.0
执行两个「下一步」：先修失真（把暗藏 maxTokens=60000 的半套接线改成成套显式声明 + 双口径并列实测），再在校准后的公平口径下用 K=3（> 上轮 2）复验软预警。校准口径 maxSteps=12 / maxTokens=120000 成为后续测量的统一尺子。
v2.33.0（本轮）
啃下悬了三轮的「下一步③ 同模型隔离锚点」：主动扫描 15 个端点/模型组合，定位限流失配根因，用测量侧节流适配让 gpt-oss-120b 稳定跑通完整 harness，产出 bro2 在有公开榜成绩同模型上的首个可复核读数，并诚实界定其 Δ 的不可归因性。

3 · 前序（v2.32.0）：下一步① 读数修正（measurement-wiring，不是能力优化）

失真机理

历史测量脚本的 configOverride 只覆盖 maxSteps=12，maxTokens 靠 agentos.config.json 默认值 60000 累计静默熔断生效。而每步上下文重建会把历史 token 重复计费——v2.31.0 实测 16 次 token 中位数 56540、最大 75138，5/16 在 4~6 步就撞 guard(tokens)，12 步预算形同虚设。报告的 budget 字段却只写了 maxModelCalls，完全没披露真正的 binding constraint。

修正 ≠ 刷分。 上一版明确拒绝「调大 maxTokens 抬高数字」。本轮把 maxTokens 提到成套值 120000（= 12 步 × 10000 token/步，依据 v2.31.0 实测约 10280 token/步），是让「名义 12 步预算」真正可用——这是修尺子，不是加资源换成绩。因此报告把两种口径并列呈现，并锁死归因。

5 · 诚实边界（红线，全程未破）

  • 小样本（4 任务、每组 K=3、共 36 次）、免费匿名端点（kilo 路由模型不固定）、单次随机性大
  • 读数修正前后通过率差归因于『测量预算接线成套化』，不是 bro2 能力变化；不写 external-results.json、不改 L4/verdict
  • 校准口径提高了 maxTokens 上限（60000→120000），这是修尺子不是加资源刷分；差异不得包装成能力优化
  • 机制复验为同集前后对照，属弱证据；软预警仍默认关闭，不因本轮改变默认行为
  • bro2 自跑、非第三方复核；公开 verifier 为上游 pytest，healthy 已双向验证
  • verifier 健全性：4/4 SOUND（沿用 v2.30.0 双向验证：空工作区 fail / 官方 oracle 解 pass）（空工作区必 fail / 官方 oracle 解必 pass，模型无关）。
  • 本轮新增：端点身份以响应 model 字段为准（BlockRun 重定向为反例）；节流是测量侧适配不是能力优化；同模型对照为非逐位同任务集的位次参照、isStrictHarnessDelta=false、名义差不可归因于 harness。
  • 全程自跑、非第三方复核；external-results.json 未被触碰（true）、leadership.verdict = not-proven、L4 = not-achieved 均未改。

7 · 当前水位与下一步

能力水位未变，但卡点推进了：v2.30.0 起「同模型隔离锚点仍需第二端点」这一悬置项，本轮从「端点限流无效」证伪为「端点可用 + 缺的是限流适配」，并已稳定跑通、产出首个同模型读数（非严格 Δ）。
下一步优先级：① 让同模型对照成为可归因 Δ——要么拿到官方 harness 在同一 4 任务子集的成绩，要么让 bro2 跑到榜单全量任务集（当前统一离线 verifier 只支持静态输入子集，需扩展）；② 在稳定端点 / 更大 K / 更多任务下把机制复验从「弱证据」推向可辩护；③ 任何改进仍走预注册判据 + 行为对比 + holdout + 二次判读，不靠分数叙事。
bro2 · Model + Harness = Agent · 冻结模型权重，只演进 harness · 只增账本 / 惰性真实探测 / 对比式改进
