# 深度调研

## 流程
1. 把大问题拆成 2–4 个独立子问题。
2. 用 `delegate` 并行派生子 Agent，每个只负责一个子问题，要求返回结论 + 依据。
3. 汇总时显式标注**一致结论**与**冲突结论**，冲突处保留双方来源。
4. 用 `file_write` 生成报告，结论段必须标注来源。

## 约束
- 子 Agent 的上下文隔离，不要把父会话的假设传给它。
- 检索结果不足时如实说明，不要用常识填补空白。
- 单个 turn 内派生数量不超过 4 个，避免 token 膨胀。
