# 数据核验与计算

## 流程
1. 先用 `file_list` / `file_read` 确认数据来源与字段含义，不要直接假设。
2. 用 `calc` 做确定性计算（支持 sum / avg / min / max / 四则运算），保留计算表达式以便复核。
3. 对异常值单独标注，说明是剔除了还是保留了。
4. 结论里同时给出**绝对值**与**相对变化**，避免只有比率。

## 注意
- `calc` 是安全表达式解析器，不支持任意代码；复杂逻辑请用 `shell` 调用脚本。
- 计算前先确认单位与口径（含税/不含税、累计/当期）。
