# 结构化报告撰写

## 使用时机
当任务要求产出一篇文章、报告、总结或正式文档时加载本技能。

## 结构骨架
1. **结论先行**：开篇用 2–3 句给出核心结论与关键数字。
2. **依据**：列出支撑结论的事实，每条标注来源（文件、工具结果或检索出处）。
3. **分析**：说明推导过程，区分「已验证」与「推测」。
4. **行动项**：给出可执行下一步，带责任与优先级。
5. **附录**：原始数据、计算过程、未解决问题。

## 质量红线
- 不臆造未执行的结果；所有数字必须来自真实工具返回。
- 引用文件时使用工作区相对路径。
- 未解决的问题单独列出，不要藏在正文里。
- 完成后用 `file_write` 落盘，并在终答里给出文件路径。
